# توضیح کامل ورودی‌های GoldBasketGuard

منبع: [`MQL5/Experts/GoldBasketGuard/GoldBasketGuard.mq5`](../MQL5/Experts/GoldBasketGuard/GoldBasketGuard.mq5)

> مقادیر پیش‌فرض در جدول‌ها همان مقادیر داخل فایل هستند (`v1.11`). برای طلا، **۱ پیپ = ۰٫۱۰ دلار** قیمت طلا (۱۰۰ پیپ = ۱۰ دلار) در نظر گرفته شده است.

> **بدون فایل پیش‌تنظیم:** از نسخهٔ ۱.۱۱ خودِ پیش‌فرض‌ها تنظیم استاندارد طلا هستند (SL گروهی ۳۰۰، TP گروهی ۵۰۰، ریسک‌فری ۲۰۰، تریلینگ پله‌ای، گارد اخبار، kill-switch روی ۱۲٪ و بریکر ۵۰٪) و اندازهٔ پیپ، ارزش هر پیپ، حساب سنتی/دلاری، hedging/netting، `STOPS_LEVEL`/`FREEZE_LEVEL`، نوع fill و ارز خبر هم موقع اجرا **تشخیص داده می‌شوند**. `tools/make_release.py` با «قرارداد صفرتنظیم» (۳۰ ورودی) پاس‌شدن این موضوع را تضمین می‌کند.

## 1) Group identification — مشخص کردن اعضای گروه

| ورودی | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `InpMagicFilter` | long | `0` | فقط معاملاتی با این magic عدد را مدیریت کن. `0` = همهٔ معاملاتِ مجازِ همین سمبل (برای مدیریت دستی معامله‌ها همین را صفر بگذارید) |
| `InpOnlyThisChartSymbol` | bool | `true` | فقط پوزیشن‌های همان سمبل که نمودار باز است (XAUUSD). برای اکانت‌های چند نمادی `false` کنید و `InpSymbolsFilter` را پر کنید |
| `InpSymbolsFilter` | string | خالی | لیست سمبل‌های مجاز، با ویرگول: `XAUUSD,XAUUSD.ec` |
| `InpCommentFilter` | string | خالی | فقط پوزیشن‌هایی که کامنتشان این رشته را دارد (مثلاً `Grid` یا نام EA شما). بهترین راه برای جدا کردن چند استراتژی روی یک نماد |
| `InpIncludeBuy` / `InpIncludeSell` | bool | `true` | جهت‌های داخل گروه |
| `InpOnlyAfterAttach` | bool | `false` | `true` = فقط معاملات بعد از اجرای اکسپرت. مفید وقتی می‌خواهید به سبد بازِ قبلی دست نزند |
| `InpIgnoreManualTickets` | bool | `false` | `true` = پوزیشن‌های بدون کامنت (دستی) را رها کن |

پنل، خط `group:` در همان تعداد پوزیشن‌های شناسایی‌شده را نشان می‌دهد. اگر صفر است، فیلترها را بررسی کنید.

## 2) Group TP / SL — حد سود و حد ضرر گروهی

| ورودی | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `InpApplyMode` | enum | `APPLY_SAME_LEVEL` | نحوهٔ پخش سطوح روی معاملات (پایین توضیح داده شده) |
| `InpSLPips` | double | `300.0` | فاصلهٔ حد ضرر گروه بر حسب پیپ. `0` = حد ضرر را دست نزن |
| `InpTPPips` | double | `500.0` | فاصلهٔ حد سود گروه بر حسب پیپ. `0` = حد سود را دست نزن |
| `InpOverwriteExisting` | bool | `true` | اگر معامله از قبل SL/TP دارد، بازنویسی شود. `false` = فقط به معاملات بی‌SL/TP اضافه کن |
| `InpAutoApplyToNew` | bool | `true` | هر پوزیشن جدیدی که باز شد، بلافاصله در همان گروه SL/TP می‌گیرد (از طریق `OnTradeTransaction`) |
| `InpAutoApplyOnStart` | bool | `true` | در لحظهٔ اجرای اکسپرت، روی پوزیشن‌های موجود هم اعمال کند |
| `InpReapplyEveryCycle` | bool | `false` | در هر چرخه دوباره اعمال کن. با `APPLY_SAME_LEVEL` باعث می‌شود سطوح **ملازم میانگین ورود** بمانند (مناسب سبدهای میانگین‌گیر) |
| `InpAbsSLPrice` | double | `0.0` | قیمت مطلق یک SL برای همهٔ گروه (مثلاً `2611.25`). اگر پر شود، `InpSLPips` نادیده گرفته می‌شود. توجه: وقتی حالت Mirror فعال است، این مقدار در زمان اجرا هم از قیمتِ دستیِ شما پر می‌شود |
| `InpAbsTPPrice` | double | `0.0` | قیمت مطلق یک TP برای همهٔ گروه |

### سه حالت `InpApplyMode`

| مقدار | رفتار | مناسب برای |
|---|---|---|
| `APPLY_PER_TICKET` | هر معامله `InpSLPips` پیپ از **ورود خودش** فاصله می‌گیرد؛ سطوح قیمتی متفاوت است ولی ریسک یکسان (به پیپ) | استراتژی‌هایی که هر ورود مستقل است |
| `APPLY_SAME_LEVEL` | **یک قیمت واحد** برای همهٔ معاملات گروه، محاسبه‌شده از میانگین وزنی ورود | سبد/شبکه‌ای: کل گروه هم‌زمان خارج می‌شود (پیش‌فرض) |
| `APPLY_FROM_WORST` | فاصله از **بدترین ورود** گروه محاسبه و همان قیمت روی همه گذاشته می‌شود | می‌خواهید سبد فقط در قیمتی خارج شود که آخرین/بدترین ورود هم سود کند |

## 3) Mirror — تنظیم یکی، اعمال روی همه (قابلیت اصلی درخواستی)

| ورودی | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `InpMirrorSL` | bool | `true` | حد ضرر یک معامله را دستی عوض (یا پاک) کنید → روی همه اعمال می‌شود |
| `InpMirrorTP` | bool | `true` | همین برای حد سود |
| `InpMirrorMode` | enum | `APPLY_SAME_LEVEL` | `APPLY_SAME_LEVEL` = همان قیمت برای همه؛ `APPLY_PER_TICKET` = همان فاصله از ورود هر معامله |
| `InpMirrorGuardSec` | int | `4` | تغییراتی که خودِ اکسپرت در این چند ثانیه ایجاد کرده نادیده گرفته می‌شود (ضد حلقه) |

وقتی شما روی یک معامله سطح را تغییر می‌دهید، اکسپرت همان را به‌عنوان منبع جدید گروه ذخیره می‌کند؛ بنابراین پوزیشن جدید بعدی هم همان سطح را می‌گیرد و تنظیم دستی شما با یک «اعمال خودکار» بازنویسی نمی‌شود. برای برگشت به حالت فاصله‌ای، عدد را در پنل تایپ کنید (یا `CLEAR SL/TP` بزنید).

نکته: «پاک کردن» حد ضرر روی یک معامله هم منتقل می‌شود (یعنی از همه حذف می‌شود) — اگر این را نمی‌خواهید، `InpMirrorSL` را خاموش کنید.

## 6) Group money targets / kill-switch

| ورودی | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `InpEnableBasketMoneyExit` | bool | `false` | بستن کل گروه بر اساس سود/ضرر ریالیِ سبد |
| `InpBasketTakeMoney` | double | `500.0` | اگر سود گروه ≥ این مبلغ → بستن همه |
| `InpBasketStopMoney` | double | `500.0` | اگر ضرر گروه ≤ −این مبلغ → بستن همه (عدد مثبت وارد کنید) |
| `InpEstCommissionPerLot` | double | `0.0` | کمیسیون تقریبی هر لات (ترن کامل) برای دقیق‌تر شدن محاسبهٔ پول |
| `InpEnableKillSwitch` | bool | `true` | حفاظ سخت: ضرر شناور گروه از X٪ equity بیشتر شد → بستن + غیرفعال‌شدن اکسپرت |
| `InpMaxDrawdownPctEquity` | double | `12.0` | آستانهٔ درصدی kill-switch (همان «۱۲٪») |
| `InpCloseAllOnKill` | bool | `true` | در kill-switch همه را ببندد یا فقط متوقف شود |

> **واحد پولی:** تمام ورودی‌های پولی این بخش (و `InpBeTriggerMoney`) روی حساب **سنتی** به‌صورت خودکار در `InpCentDivisor` ضرب می‌شوند تا شما دلار واقعی تایپ کنید (با `InpMoneyBasis` قابل تغییر است). ورودی‌های **درصدی** هیچ تبدیل نمی‌خواهند و روی هر ارزی از حساب یکسان کار می‌کنند — برای مدیریت سرمایه، درصد را ترجیح دهید.

پس از فعال‌شدن kill-switch، اکسپرت تا اجرای مجدد **غیرفعال** می‌ماند (پنل `KILL-SWITCH ACTIVE` را نشان می‌دهد).

## 8) News guard — گارد اخبار (Red Folder)

| ورودی | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `InpNewsEnabled` | bool | `true` | روشن/خاموش کردن گارد اخبار (دکمهٔ `NEWS` روی پنل هم همین را عوض می‌کند) |
| `InpNewsImportance` | enum | `CALENDAR_IMPORTANCE_HIGH` | کمترین اهمیت برای واکنش. `HIGH` = همان پوشهٔ **قرمز** در تقویم MT5 |
| `InpNewsIncludeModerate` | bool | `false` | `true` = به **نارنجی**ها (`MODERATE`) هم واکنش نشان بده |
| `InpNewsBeforeMin` | int | `20` | چند دقیقه قبل از خبر وارد حالت احتیاط شو |
| `InpNewsAfterMin` | int | `15` | چند دقیقه بعد از خبر هم در حالت احتیاط بمان |
| `InpNewsCurrencies` | string | خالی | ارزهایی که رصد می‌شوند: `USD` یا `USD,EUR,GBP,JPY`. خالی = از نام سمبل استخراج کن (برای طلا همان USD) |
| `InpNewsAction` | enum | `NEWS_CLOSE_GROUP` | `NEWS_WARN` فقط هشدار / `NEWS_RISK_FREE` ریسک‌فری / `NEWS_CLOSE_LOSING` بستن زیان‌ده‌های گروه / `NEWS_CLOSE_GROUP` بستن کل گروه / `NEWS_CLOSE_ACCOUNT` بستن **همهٔ پوزیشن‌های اکانت** |
| `InpNewsPauseAutomation` | bool | `true` | داخل پنجرهٔ خبر، اعمال/بازنویسی خودکار SL-TP متوقف شود (ریسک‌فری، breaker و بستن همچنان فعال) |
| `InpNewsTightenBeforeClose` | bool | `true` | قبل از بستن، حد ضررها را روی نقطهٔ ریسک‌فری بگذار (کمک به خروج با ضرر کمتر در صورت لغزش قیمت) |
| `InpNewsManualWindows` | string | خالی | جایگزین دستی/آفلاین: `"[DOW-]HH:MM-HH:MM;..."` با **زمان سرور**. مثال: `1-14:30-14:45;5-12:00-13:30` (DOW: ۰=یکشنبه). تنها راه کار در Strategy Tester |
| `InpNewsRefreshSec` | int | `30` | دورهٔ پرس‌وجوی تقویم (ثانیه). کمتر از این نباشد تا خطای محدودیت سرور (`5204`) نگیرید |

نکته‌ها:
- همهٔ توابع تقویم MT5 با **زمان سرور ترید** (`TimeTradeServer`) کار می‌کنند؛ همان ساعتی که در تب Economic Calendar می‌بینید.
- تقویم اقتصادی در Strategy Tester در دسترس نیست؛ در آن حالت خودکار به `InpNewsManualWindows` برمی‌گردد و در پنل پیام `calendar not available in tester` را می‌بینید.
- اکسپرت برای **هر رویداد یک بار** اقدام می‌کند (تا وقتی همان خبر در پنجره است دوباره همه را نمی‌بندد)؛ اگر می‌خواهید در طول کل پنجره وارد نشوید، گارد را با `InpNewsAction=NEWS_CLOSE_ACCOUNT` و توقف خودکار ترکیب کنید.
- اگر تقویم خطا بدهد، پنل `calendar err <code>` نشان می‌دهد و اکسپرت هیچ بسته‌ای را بر اساس دادهٔ ناقص نمی‌بندد (فقط پنجره‌های دستی اعمال می‌شوند).

## 9) Risk sizing, money units, broker adaptation

| ورودی | نوع | پیش‌فرض | توضیح |
|---|---|---|---|
| `InpRiskPctPerBasket` | double | `0.0` | عدد مثبت = حد ضرر گروه از «٪ ریسک از موجودی» محاسبه می‌شود: `pips = (balance × ٪) / (ارزش هر پیپ × حجم کل گروه)`. با بزرگ‌شدن سبد، حد ضرر خودکار کوتاه‌تر می‌شود. اگر خودتان روی یک معامله سطح را دستی ست کرده باشید (`g_absSl`)، آن سطح حفظ می‌شود و این فقط برای نمایش محاسبه می‌شود |
| `InpRiskRewardRatio` | double | `0.0` | حد سود = این مضرب × حد ضرر (R multiple). `0` = همان `InpTPPips` |
| `InpRiskCapPips` | double | `0.0` | سقف فاصلهٔ حد ضرر مجاز (پیپ) |
| `InpRiskFloorPips` | double | `80.0` | کف فاصله (روی طلا اجازه ندهید حد ضرر به اندازهٔ اسپرد تنگ شود) |
| `InpEmergencyFloatLossPct` | int | `50` | **قانون ۵۰٪ شما**: اگر ضرر شناور کل اکانت ≥ این ٪ از موجودی شد → بستن همه + قفل. `0` = خاموش |
| `InpEmergencyEquityDdPct` | double | `0.0` | افت equity از بیشینهٔ ثبت‌شده ≥ ٪ → بستن همه (بیشینه در GlobalVariable ذخیره می‌شود و با ریستارت اکسپرت از نو صفر نمی‌شود) |
| `InpEmergencyMarginLevelPct` | int | `150` | Margin level به زیر این ٪ برود → بستن همه (نزدیک Stop Out). `0` = خاموش |
| `InpEmergencyFreeMarginPct` | int | `0` | مارجین آزاد ≤ این ٪ از equity → بستن همه |
| `InpEmergencyStepDown` | bool | `false` | `true` = به‌جای بستن همه، بدترین ضررده یکی‌یکی بسته شود (مگر در آستانهٔ استاپ‌اوت که همه بسته می‌شود) |
| `InpEmergencyLockHours` | int | `24` | بعد از فعال‌شدن breaker، اکسپرت N ساعت قفل می‌ماند (`UNLOCK` / کلید `7` برای باز کردن دستی) |
| `InpDailyLossLimitPct` | double | `0.0` | حد ضرر روزانه (٪ از موجودی ابتدای روز) → توقف تا شروع روز معاملاتی بعد |
| `InpDailyProfitTargetPct` | double | `0.0` | هدف سود روزانه → توقف برای بقیهٔ روز |
| `InpDailyCloseOnLimit` | bool | `true` | با خوردن حد روزانه، گروه هم بسته شود |
| `InpMoneyBasis` | enum | `MONEY_AUTO` | معنی اعداد پولی: `MONEY_AUTO` = روی حساب سنتی خودکار ×۱۰۰ (شما دلار واقعی تایپ می‌کنید)، `MONEY_ACCOUNT_CCY` = دقیقاً واحد ارز حساب (سنت)، `MONEY_REAL_USD` = همیشه ×`InpCentDivisor` (برای کارگزارانی که تشخیص خودکار جواب نمی‌دهد) |
| `InpCentDivisor` | double | `100.0` | چند واحدِ حساب = یک واحد واقعی (برخی بروکرها ۱۰۰۰) |
| `InpAdaptiveStops` | bool | `true` | اگر سرور سطح را با `invalid stops` رد کرد، حاشیهٔ محافظتی خودکار زیاد و دوباره تلاش می‌شود |
| `InpAdaptiveStopsCapPoints` | int | `300` | سقف همان حاشیه (پوینت). مقدار فعلی در پنل: `stops 0 pt (+N ad)` |

### تشخیص حساب سنتی / دلاری

ارز حساب از `AccountInfoString(ACCOUNT_CURRENCY)` خوانده می‌شود. کدهای شناخته‌شدهٔ سنتی: `USC`، `EUC`، `GBC`، `RUC`، `AUC`، `JYC`، `CHC`، `BRC` و هر کدی که `CENT` در آن باشد. خط اول پنل همیشه `(cent)` را کنار ارز حساب نشان می‌دهد؛ اگر نبود، یعنی حساب استاندارد است. روی همهٔ کارگزارها (حتی با نام‌های سمبل `XAUUSD.ec`، `GOLD`، `XAUUSDm`) فیلترها بدون حساسیت به حروف بزرگ/کوچک تطبیق داده می‌شوند و مقدار `pip`، `digits`، `stops level`، `freeze level` و حالت `hedging/netting` زنده از خود سمبل/اکانت خوانده می‌شود.

## دکمه‌ها و کلیدهای میانبر

| کلید | دکمه | عمل |
|---|---|---|
| `1` | `APPLY TP+SL` | اعمال حد سود و حد ضرر گروهی روی همهٔ معاملات (همان لحظه) |
| `2` | `APPLY SL` | فقط حد ضرر گروهی |
| `3` | `APPLY TP` | فقط حد سود گروهی |
| `4` | `RISK-FREE NOW` | بدون توجه به آستانه، همه را همین حالا ریسک‌فری کن |
| `5` | `TRAIL ON/OFF` | روشن/خاموش کردن تریلینگ |
| — | `CLEAR SL/TP` | حذف حد ضرر و حد سود از همهٔ معاملات گروه (برای مدیریت دستی بحران) |
| — | `CLOSE ALL` | بستن کل گروه — **دو بار کلیک** لازم است |
| — | `CLOSE LOSERS` | فقط معاملات زیان‌ده — **دو بار کلیک** |
| `6` | `NEWS ON/OFF` | روشن/خاموش کردن گارد اخبار |
| `7` | `UNLOCK` | باز کردن قفل kill-switch / breaker / حد روزانه |
| `0` | `PAUSE / RUN` | توقف/ادامهٔ کل خودکارسازی (پنل همچنان اطلاعات را نشان می‌دهد و گاردهای اضطراری همیشه فعال‌اند) |

فیلدهای قابل ویرایش روی پنل: `SL pips`، `TP pips`، `BE arm`، `BE lock`، `Trail dist` — بعد از تایپ `Enter` بزنید؛ دکمهٔ `1` از همان مقادیر استفاده می‌کند.
